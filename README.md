# 路安作业区 · 3D

高速公路养护作业区（JTG H30）布置图工作台。独立网页，左栏调参数、中间看 3D 微缩沙盘、右侧实时联动 2D 规程布置图；计算规则与 `construction-hub` / 小程序同源。

![界面截图](docs/screenshot.png)

## 功能

- **规程计算（JTG H30）**：自动解算警告区、上游过渡区、缓冲区、作业区、下游过渡区、终止区的起止桩号与长度，支持路侧 / 中分带单侧 / 中分带双向作业，限速阶梯（60/40 或 80/60）自动匹配。
- **3D 微缩沙盘**：纯代码程序化生成路面、标线、波形梁护栏、中分带防眩板、锥桶（InstancedMesh）、标志牌（点击查看高清图解与桩号）、防撞缓冲车与工程车（带爆闪警示灯）；轿车 / SUV / 货车混合车流，先并入开放车道、驶过终止区后并回原车道。
- **2D 规程布置图**：与 3D 同源的实时矢量图，含桩号刻度、分区标注与标志点位；双侧占路自动拆分上 / 下行两段。
- **导出**：
  - 「导出布置图」：A4 规范图，单侧 2 张 PNG（布置图 + 设施一览表），双侧占路 3 张（上 / 下行布置图 + 一览表）；
  - 「截图」：仅 3D 画面，或含面板与图例的合成图。
- **参数持久化**：桩号、长度等参数与左右两栏的收起状态保存在本地，刷新不丢。

## 技术栈

- Vite 7 + React 19 + TypeScript
- Three.js + React Three Fiber (`@react-three/fiber` 9) + `@react-three/drei` 10
- 2D 图为 SVG 动态绘制；导出经 `html-to-image` 合成 A4
- 纯程序化几何，不依赖 Blender 等外部模型

## 目录结构

```text
src/
├── zone/       # JTG H30 分区算法、桩号解析与校验、数据类型
├── layout/     # 断面尺寸、坐标展开、设施点位解算、车流动线
├── scene/      # R3F 3D 场景：路面、标线、护栏、锥桶、标牌、工程车、车流
├── diagram/    # 2D 矢量布置图与 A4 一览表 SVG 生成
├── ui/         # 参数栏、2D 布置图栏、顶栏视控、HUD、导出逻辑
└── persist.ts  # localStorage 参数与面板状态持久化
```

## 开发与构建

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b && vite build（已配置 vendor 分包）
npm run preview
```
