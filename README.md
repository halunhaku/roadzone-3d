# 路安作业区 · 3D

高速公路养护作业区（JTG H30）布置图的浏览器 3D 版。独立网页，计算与 `construction-hub` / 小程序同一套分区规则。

## 技术栈

- **构建/框架**：Vite 7 + React 19 + TypeScript
- **3D 渲染**：Three.js + React Three Fiber (`@react-three/fiber` 9) + `@react-three/drei` 10
- **几何生成**：纯代码程序化几何体（路面、标线、InstancedMesh 批量锥桶、动态车流），不依赖外部 3D 模型
- **出图导出**：SVG 动态绘制 + `html-to-image` A4 规范导出

## 核心功能

1. **规程计算（JTG H30）**
   - 自动解算警告区、上游过渡区、缓冲区、作业区、下游过渡区、终止区起止桩号与米数。
   - 支持路肩封闭、中央分隔带封闭、双向作业等工况，并计算限速阶梯（60/40 或 80/60）。
2. **3D 场景与动态演示**
   - 程序化路网与车道标线生成。
   - 批量锥桶与标准养护作业标志牌立杆放置。
   - 沿行车方向的动态车流演示，支持变道避让与封闭车道禁入。
   - 视角自由控制（旋转、缩放、视角复位）。
3. **交互与出图**
   - 标志牌交互：点击场景中标志牌查看详细信息与桩号。
   - 3D 截屏导出（纯场景 / 含 UI 与图例）。
   - A4 双页布置图导出（第一页平面布置图，第二页安全设施设置一览表）。

## 目录结构

```text
src/
├── zone/       # JTG H30 分区算法、桩号解析与校验、数据类型
├── layout/     # 断面尺寸定义、坐标展开、设施布置点位解算、车流避让路径
├── scene/      # R3F 3D 场景、路面材质、标线、锥桶、标志牌、车流组件
├── diagram/    # 2D 矢量平面图与 A4 设施一览表 SVG 生成
└── ui/         # 参数调节面板、视角与导出控制栏、HUD、导出生成逻辑
```

## 开发与构建

```bash
# 安装依赖
npm install

# 启动本地开发服务器
npm run dev

# 生产打包（已配置 Three.js / React manualChunks 分包）
npm run build

# 预览构建产物
npm run preview
```
